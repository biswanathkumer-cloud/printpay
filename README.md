# PrintPay v17 — Counter Payment + QR Poster + Desktop Owner Software

- Counter-only payment; no online payment gateway.
- Customer QR poster at `/poster`.
- Owner panel includes QR link, poster print/save-PDF, QR PNG download, pricing, voice and printer settings.
- B&W and Colour can use separate Windows printers.
- Owner can download `PrintPay_Desktop_Software.zip` from the Owner panel.
- Desktop app handles Owner login, cash Payment Received, printer settings and automatic printing without keeping the Owner web page open.
- Customer files are relayed temporarily and are not stored permanently in D1/R2.
- PDFs are temporary on the shop PC only while printing and are deleted afterward.
- Desktop app is source-based/portable; it is not a digitally signed EXE in this package.
