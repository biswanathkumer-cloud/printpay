⚙️ Price / Printer / Voice Settings

Web-only version: browser security-এর কারণে website Windows-এর installed printer list সরাসরি পড়তে বা silently printer select করতে পারে না। “Test / Open Browser Printer” চাপলে browser-এর print dialog খুলবে; সেখানে Windows-এর USB/Wi‑Fi/LAN installed printer list দেখা যাবে। Printer Name fields শুধু reference হিসেবে রাখা হয়েছে।

Printer setup: Windows-এর যে PC-তে এই Owner page খোলা আছে, সেখানে Settings → Bluetooth & devices → Printers & scanners থেকে USB/Wi-Fi/LAN printer আগে install করুন। তারপর Test / Open Browser Printer চাপুন। Security: Owner password ও Print Station Key কাউকে দেবেন না। শুধু নিজের HTTPS PrintPay address ব্যবহার করুন।
