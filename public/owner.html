⚙️ Price / Printer / Voice Settings

B&W and Colour can use separate Windows printer names. Automatic printing is handled by the PrintPay Desktop software.

🖥️ PrintPay Desktop Software

Browser ছাড়াই Owner payment + printing control করতে চাইলে এই software PC-তে install/run করুন.

  • Owner login desktop app-এর ভিতরেই হবে
  • Customer-এর cash payment receive করে এখান থেকেই Payment Received করা যাবে
  • Payment Received হলে automatic print job যাবে
  • B&W / Colour আলাদা printer select করা যাবে
  • Customer PDF permanent storage-এ রাখা হবে না; print-এর সময় temporary file তৈরি হয়ে delete হবে
  • Software Windows Administrator permission চায় না

প্রথমবার Windows-এ dependency install করতে হবে। Package-এর install_desktop.bat আছে।

Security: Owner password ও Print Station Key কাউকে দেবেন না। শুধু নিজের HTTPS PrintPay address ব্যবহার করুন।
