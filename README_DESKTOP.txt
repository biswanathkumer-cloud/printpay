PRINTPAY DESKTOP
================
1. On the Owner web panel, set a strong Print Station Key and printer names.
2. Download this package and run install_desktop.bat once.
3. Run PrintPayDesktop.py. This is a desktop control app; it does not need the Owner web page open.
4. Login with Owner username/password and the Print Station Key.
5. Keep the app running. When a customer order arrives, double-click it, confirm cash received, and printing is unlocked automatically.
6. Customer PDFs are held only temporarily in memory / a temporary local PDF while printing, then deleted.

SECURITY NOTES
- Use only the HTTPS PrintPay URL.
- Do not share the Print Station Key or Owner password.
- The app does not need Windows Administrator rights.
- The package is source-based, not a signed EXE. Windows may show warnings for scripts depending on policy.
